# Restaurant Management System — Backend

Node.js/Express/MongoDB backend for a Restaurant Management System capstone project.

## Team
- Kater — Auth, Menu/Order Management, Billing/Payment
- Maleek — Table Reservation/Seating, Kitchen/Inventory
- Rufus — CRM, Reporting/Analytics

## Setup
1. `npm install`
2. Copy `.env.example` to `.env` and fill in values
3. `npm run dev`

## Branching
- No direct pushes to `main`
- Create a feature branch: `git checkout -b feature/your-feature`
- Open a PR into `main` when ready for review
